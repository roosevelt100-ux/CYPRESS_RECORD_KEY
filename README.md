# Greicin Ateliê — site atualizado

Esta versão incorpora os SVGs enviados como referências e imagens do catálogo, além da identidade visual premium.

## Estrutura
- `index.html` — site público
- `admin.html` — cadastro local de produtos
- `assets/` — logo e anexos SVG
- `css/style.css` — identidade, responsividade e layout
- `js/main.js` — menu e orçamento via WhatsApp

## Publicação no Netlify
Faça upload da pasta do projeto no Netlify ou conecte o repositório Git. O site é estático e não exige build.

## Observação
A URL `https://greicinatelie.netlify.app` respondeu com HTTP 401 no momento da verificação, então não foi possível editar o deploy remoto diretamente. Esta pasta contém a versão pronta para substituir o conteúdo atual no Netlify.
